INSIGHTORY Tools

INSIGHTORY Tools は、YouTube チャンネル「INSIGHTORY / 海外最前線ファイル」の運営者が、自分のチャンネルだけのために使う制作・分析ツールです。

  • 運営者自身のチャンネルの再生回数・視聴時間などの分析データを読み取り、運営者に日次・週次で報告します。
  • 運営者自身が制作した動画を、運営者自身のチャンネルにアップロードします。

このツールは一般には提供していません。第三者のチャンネルやデータにはアクセスしません。

INSIGHTORY Tools uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service.
