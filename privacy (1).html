プライバシーポリシー（INSIGHTORY Tools）

最終更新日：2026年10月31日

1. このツールについて

INSIGHTORY Tools（以下「本ツール」）は、YouTube チャンネル「INSIGHTORY / 海外最前線ファイル」の運営者が、自分のチャンネルの運営のためだけに使うツールです。本ツールは YouTube API Services を利用しています。

2. 取得する情報

本ツールは、運営者が Google アカウントで許可した範囲で、次の情報だけを YouTube API Services から取得します。

  • 運営者自身のチャンネルの基本情報（チャンネル名・ID）
  • 運営者自身のチャンネルと動画の分析データ（再生回数、視聴時間、クリック率、視聴者の維持率など）
  • 運営者自身がアップロードする動画とその説明文・サムネイル・字幕

視聴者個人を特定できる情報は取得しません。

3. 情報の使い方

取得した情報は、運営者への日次・週次の報告（運営者専用の Slack）と、運営者自身のチャンネルへの動画のアップロードにだけ使います。広告や第三者への提供、販売には使いません。

4. 保存と削除

認証情報と取得したデータは、運営者のコンピューターにのみ保存します。分析データは最長で30日分を保存し、それより古いものは削除します。運営者は、Google アカウントのセキュリティ設定（サードパーティのアクセス）から、いつでも本ツールへの許可を取り消せます。取り消した場合、本ツールは保存している認証情報とデータを削除します。

5. Google のプライバシーポリシー

本ツールは YouTube API Services を利用しているため、Google プライバシーポリシーも適用されます。また、YouTube 利用規約に従います。

6. お問い合わせ

YouTube チャンネル「INSIGHTORY / 海外最前線ファイル」の概要ページからご連絡ください。

Privacy Policy (INSIGHTORY Tools)

INSIGHTORY Tools is used only by the operator of the YouTube channel "INSIGHTORY" to manage that channel. It uses YouTube API Services. With the operator's authorization, it accesses only the operator's own channel information, channel/video analytics, and videos the operator uploads. No information identifying individual viewers is collected. Data is used only to report to the operator and to upload the operator's own videos; it is never sold or shared with third parties. Credentials and data are stored only on the operator's computer; analytics data is kept for up to 30 days. Access can be revoked at any time via Google security settings, after which stored credentials and data are deleted. The Google Privacy Policy and YouTube Terms of Service apply. Contact: via the INSIGHTORY YouTube channel page.
